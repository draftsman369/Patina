# Getting started

## Opening a mesh

- **File › Open mesh…** (Ctrl+O) opens an OBJ, glTF or GLB file.
- **File › New project…** (Ctrl+N) opens the New Project dialog: pick a mesh
  or a primitive, the document resolution and the normal map format
  (OpenGL or DirectX).
- **File › New from primitive** starts from a sphere, cube, cylinder, torus or plane.
- **File › Open recent** lists the last ten meshes.
- You can also **drag a mesh file** onto the window.

Patina needs UV coordinates to texture a mesh. Meshes without UVs open, but
the status bar warns you; automatic unwrapping arrives in M10.

## The interface

| Area | Content |
|---|---|
| Menu bar | File, Edit, Mode, Window, Viewport, Help |
| Left bar | Painting tools (inactive until M4) |
| Center | 3D viewport and 2D UV view |
| Right panel | Texture Set List, Layers, Properties, Display Settings |
| Bottom | Shelf (environments today, the asset library in M6) and status bar |

Panels can be hidden from the **Window** menu.
