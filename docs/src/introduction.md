# Introduction

Patina is an open-source, local-first 3D texture painting application. You
load a mesh, paint PBR materials directly on it through a layer stack, and
export textures for game engines and renderers.

This manual tracks the current state of the project. Features that are not
implemented yet are listed in the [roadmap](https://github.com/draftsman369/Patina/blob/main/ROADMAP.md),
by milestone.

**Done so far: M1 (viewport and UI shell) and M2 (HDRI lighting and
baking).** You can open meshes, light them with HDRIs, inspect channels and
the UV layout, load images into channel slots and bake mesh maps. The layer
stack arrives in M3 and painting in M4.
